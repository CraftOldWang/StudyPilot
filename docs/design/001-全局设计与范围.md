# StudyPilot 产品范围

更新于 2026-09-22。本文汇总用户已经确认的当前产品行为；架构见 [技术设计](StudyAgent-技术设计方案.md)，执行状态只见 [PROGRESS](../../PROGRESS.md)。早期 M0–M8 计划是历史实施背景，不再覆盖这里的当前范围。

## 1. 用户与目标

面向课程学习和期末备考的桌面浏览器演示应用。用户上传课件和可选往年题，生成可复用大纲，在知识点对话中完成讲解、练习、答疑和复习卡。

本地使用演示身份；已准备口令保护的在线共享演示配置，不建设注册、独立用户账号或复杂权限系统。上线尚需服务器/域名等条件。

## 2. 页面组织

- 左侧品牌标志、创建新对话、资料库、学习记忆、独立测试工具入口。
- 知识库像项目一样分组，内部会话按最近更新时间排列，点击恢复；长标题截断，悬停查看完整名称。
- 对话区和侧栏各自滚动，输入框固定，工具调用默认折叠。
- 资料库页管理知识库、文件上传和处理状态；音视频依赖本地转写服务。
- 大纲在独立页面展示多层待办树，叶子是学习任务，父节点汇总完成状态。只展示目录、进度和简短重点标签，来源与详细讲解在聊天中查看。
- 测试工具是独立页面：左选普通检索、Agent 检索、Trace、评测、Hello，右侧操作。

## 3. 大纲与聊天

一份当前大纲绑定知识库；选入课件后分批提取、合并，选入习题后标注重点。知识点数量由资料决定。新聊天复用大纲，不重复规划。

每个聊天有独立消息、知识点学习实例、测验、卡片和上下文；同一大纲叶子的完成情况跨关联聊天汇总。新聊天跳过已完成节点，已开始聊天保留自己的在途路径。重新生成大纲不自动迁移旧进度。

## 4. 知识点学习

1. Agent 根据大纲和资料讲解，用户可以持续追问。
2. 用户表达准备好后，Agent 通过工具发布选择题；每组 1–10 道，由工具和后端限制。
3. 提交后评分、解释错误，继续答疑。
4. 用户准备结束时生成 1–10 张复习卡草稿；用户可编辑或要求重写。
5. 全部确认后保存/导出，再推进下一知识点。本地版导出 Anki，在线 demo 版保存在站内。

进入写卡阶段时并行总结该知识点写卡前的对话；确认前保持原上下文，确认后才替换为摘要并丢弃卡片讨论。摘要有损，完整历史仍持久化。

## 5. 跨会话记忆

支持用户自述讲解偏好、长期目标，以及评分时记录的知识点与错题观察。按用户和知识库读取其他会话记录，限制条数和 token；可以关闭、排除单条记录或重新纳入。不推断人格，也不将一次成绩当成稳定掌握度。

## 6. 当前不包含

站内 FSRS 调度、Anki 学习反馈回流、知识图谱、独立多租户账号、移动端适配、多 Agent 团队，以及为了简历数字预设某种检索策略必然更好。

保留真实检索和上下文压缩实验；历史指标按当时资料、脚本、参数和判读口径解释，不作为所有课程的性能保证。日常开发不以重跑整套模型实验为门槛。
