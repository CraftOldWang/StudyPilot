## 有解释价值的差异

1. **RRF补回评分题、丢失书单题，总命中数持平。** 第2题VECTOR第1条就有教材和参考书单；BM25未检出，融合后正确子块未进入前5。原第1题则相反，由关键词路线补回评分规则。
2. **第13题父块预算丢证据。** VECTOR和RRF第3条直接写明寻找足够大的空闲分区、分割并标记；父块回填先保留换页主题的大块，最后没有留下分区分配职责的直接依据。
3. **同为命中不表示完整性相同。** 第25题VECTOR有代码、数据、堆等段的图示文字；RRF第3条额外带回完整段列表，包括子模块、公用库、初始化数据、符号表。按允许部分依据的口径两者都算命中，但RRF的证据更完整。
4. **父块不是必然增加有用信息。** 第19题父块保留覆盖/分区对换，却缺少虚拟存储原理；第27题父块保留LRU栈例图和访问顺序，但丢失前一子块的栈/链表完整操作步骤。两题仍有部分实质依据，因此粗粒度指标没有扣分。
5. **EAS是多块覆盖的例子。** VECTOR包含目标、能耗比较规则和迁移案例；RRF和PARENT保留节能迁移案例，缺少完整目标/规则。按当前口径仍计命中，不应解读成回答质量相同。

这批结果支持“已测问题上纯向量已覆盖大部分信息需求，额外策略没有总体命中收益”，不支持“各策略回答效果相同”或“父块普遍无用”。当前回填的整块预算处理有已观察到的局限，结果仅适用于这个实现。用户尚未在本轮要求修改默认检索策略，因此本轮只补测和整理，没有切换业务默认值。

## 简历建议

- 基于Elasticsearch封装课程资料RAG检索工具，为讲解与测验提供可追溯依据；构建28道人工课程问题的检索评测集，对比关键词、向量、RRF融合及父块回填策略，分析检索命中与上下文完整性的取舍。
- 在阈值压缩之外，按知识点完成边界进行局部摘要压缩，保留关键结论与学习状态；固定5知识点、31轮学习流程中，相比不压缩，累计输入token减少约62%（含摘要调用）；持久化摘要与会话状态，支持中断恢复。

压缩实测为`1 - 390101 / 1041780 = 62.55%`，首轮为61.23%，不是62.3%。这是累计输入，不是单次上下文压缩率或费用降幅；两组学习模型调用为53/46次，属于相同用户脚本的Agent工作流对照，不能把所有差异归为固定调用列表的纯摘要效果。未测试“相比仅阈值压缩”的降幅。完整口径见[当前压缩实验](current-learning-compaction.md)。
